## Security and Privacy

Voting privacy is an intended feature of this project. The implementation and its tests should be reviewed to verify that voter identity is not linked to individual vote choices, and that duplicate voting is prevented on the server side.

Do not use this project for a real election without an independent security review, appropriate testing, and operational safeguards.
